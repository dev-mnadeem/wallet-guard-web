Real API transcript.

MongoDB 8.2), started from a fresh copy of the repository with:

    JWT_SECRET=$(openssl rand -hex 48) docker compose up --build -d

and driven with curl on http://localhost:8650. Every status code and body is
verbatim apart from the JWT, which is cut after six characters. The Socket.IO
lines at the end are raw Engine.IO polling frames sent to /socket.io/.
